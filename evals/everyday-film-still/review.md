# 日常电影剧照 · v0.1.0 审片

2026-09-09。三张不同题材原照片，内置 image_gen 三张有效输出。默认纯图；另以早餐测试可选字幕。不是独立盲测或传播率实验。

| 样例 | 结果 | 边界 |
|---|---|---|
| 猫 | 眼睛、耳形、趴姿与桌面关系可辨认；夜间屏幕光与浅景深突出陪伴感，暗部仍可读。 | 环境与细小纹理重构；未验证人物身份。 |
| 长椅 | 空位、木条与支撑结构、斜向透视保留；暖光和道路留白构成环境空镜。 | 原背景路人按提示词省略，植被重构；故事性较弱，不将等待感当客观事实。 |
| 早餐 | 四只可颂、草莓、黄油、桌布与玻璃杯的关系保留；明亮自然光成立。字幕“再坐一会儿吧。”目视准确，白字与轻阴影可读。 | 食物细节重绘，观感仍带美食摄影特征；只验证一句字幕。 |

三张均为真正的横向宽画布，无黑条伪装、海报文字或其他 Skill 风格元素。目标为约 2.39:1，实际尺寸见清单，约 2.38:1。对本款的近似宽银幕采用 0.5% 相对比例容差；其他样例默认检查不变。不是承诺精确交付指定像素尺寸。

三种题材支持这次有限首发。不同模型、人像、多人和用户分享意愿尚未验证；用户可以无字幕或指定原创台词，不将示例中的时间、配色或台词固定给所有照片。
