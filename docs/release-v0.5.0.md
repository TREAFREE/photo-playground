# Photo Playground v0.5.0 · 十一款独立照片 Skills

新增三款原创风格：

- bead-memory-tile：拼豆纪念画，规则 v0.1.0。
- spot-ink-editorial：单双色网点海报，规则 v0.1.0。
- photo-poetry-diptych：摄影与微小诗意，规则 v0.1.0。

完善另外七款的复杂输入处理，并各增加一个来源照片测试：博物馆 v0.2.1、像素 v0.3.1、悬赏令 v0.1.2、电影 v0.1.1、纸雕/记忆册/说明书各 v0.1.1。日报包未改动；未合并此前未采纳的像素分支。

本轮十五次出图、十三张最终样例，保留双联版缩小插画、电影版去掉扩图植物的前后记录。每款独立 ZIP，另附单包校验与 SHA256SUMS。安装完整同名目录即可，已有同名自定义版本先备份。

已发布不等于任意照片稳定成功。当前仅有内置 image_gen 的小规模样例验证，豆包/其他模型、人像身份保持、日文小字未测。拼豆不是施工图；网点图不是可制版分色；摄影双联长椅仍约 57/43 分割，未达到严格五五。详细记录见仓库 docs/skill-status.md 和 examples/review-v0.5.0/README.md。

用户截图仅用于理解风格，没有打包或公开截图。样例使用仓库已有来源照片，遵循原许可；安装包不含第三方照片。使用者自己提供图片生成环境，不托管推理或销售额度。
