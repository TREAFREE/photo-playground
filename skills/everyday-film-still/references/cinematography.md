# 摄影语言

以可辨认的生活场景为基础，通过构图、光与动作关系建立情绪。默认实拍质感，禁止像素、漫画排线、旧纸海报、展台或标题布局。

- 默认真正的宽画面约 2.39:1，不在原比例上加黑条假装完成。不把主体拉宽；扩展环境或重新取景需保留关键空间关系。
- 让视线或动作指向一片有意义的空间。近景、焦点和背景分开组织，避免所有部分同样清晰。
- 光要有方向和来源：电脑屏幕、窗口或太阳可作为已有依据。日夜和色温可以改编，但不随意加灯具、霓虹或烟雾来凑氛围。
- 色彩按场景需要选择，使用自然的阴影与高光过渡；不要一律橙青配色。暖光与冷暗部可以出现，但不过饱和。
- 暗场中主体眼睛、轮廓和重要动作仍需可读。轻微颗粒与光晕可以辅助，不遮盖材质，不产生过锐 HDR 观感。
- 允许电影式省略次要路人或杂物，但要记录重构；主要人物不得擅自增减。
- 同一种输入可有不同电影情绪。不要把首轮深夜猫或暮色公园固定成所有照片的滤镜。
