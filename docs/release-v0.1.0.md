# v0.1.0 · 没什么大事日报

把照片里的小事，认真登上头版。

首个原创免费 Skill，支持照片专属冷幽默文案、横竖照片自适应排版与一次针对性修订。

- 5 张实测源照片：猫、长椅、黑白狗照、早餐、衣物。
- 保留 7 个生成版本，包括不合格的横版狗稿及修订记录。
- 内含可安装的 `small-news-daily.zip`、MIT 许可和 SHA-256 校验文件。
- 当前实测环境：Codex 内置参考图片编辑工具。没有捆绑模型、Key 或调用额度。
- 生成式编辑可能改变原照片细节，不承诺像素级保真。

解压后把 `small-news-daily` 放入自己的 Skills 目录，上传照片并输入：
