# 第一轮视觉测试

仅测试 `small-news-daily` 一个效果。两个题材用于检验同一 Skill 的横竖图适配，不是两个不同 Skill。

## Cat — 横图 / 深色主体 / 前景遮挡

请求：把这张猫照片做成《没什么大事日报》，有一点冷幽默，文字用中文。

事实：深色玳瑁猫、金黄色眼睛、左侧电脑、右前景书本；猫坐着，没有证据表明它正在输入。

角度选择：“新同事到岗、主要负责盯人”。舍弃“猫在写代码”，因为照片不支持。

构图：上方标题，中间横照片，下方两栏短报道。

检查：猫身份与眼睛、电脑/书本相对关系、文字逐字、标题一眼可读、没有伪机构或额外日期。

## Bench — 竖图 / 斜向透视 / 无主角人物

请求：把这张长椅照片做成《没什么大事日报》，温柔地好笑，文字用中文。

事实：空的近处长椅、弯曲扶板/座面边缘、背景树木与失焦远处人物。

角度选择：“公开招募发呆的人”。不推测拍摄者感情经历，不把背景人物抹除。

构图：左侧标题与短文，右侧完整竖照片，下方短栏。

检查：长椅形状、主座位仍空、照片没有被横裁成碎片、标题不过窄、与猫版有共同报头和层级。

## 通过与限制

- 所有定稿中文准确、主体身份可认、无明显裁切/版面缺陷，才能作为演示候选。
- 每项问题记具体观察，不以“高级感 9 分”替代证据。
- 这次由当前 Agent 执行 Skill 并审片，不是盲测或跨模型兼容测试。
- 不根据两张演示断言任意照片稳定出图、像素级原片保留或传播效果。
