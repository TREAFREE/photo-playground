# v0.3.0 · 像素生活存档

新增第三个原创照片 Skill：将照片里的宠物或风景重绘为卡通像素场景，配可选的短生活存档文案。

首轮实测桌边猫、公园长椅；保留 3 张有效输出、实际提示词、审片与一次服务失败后重试的记录。猫修订版减少碎毛发，强化卡通形体；长椅保留来源斜向透视并重构树林。

下载 `pixel-life-save.zip`，解压后放入 Skills 目录，附图输入：

> 使用 $pixel-life-save，把这张照片做成卡通像素风，保留主体特征，配一句中文生活存档文案。

另外两个 ZIP 继续提供小报和博物馆 Skill，内容与 v0.2.0 相同。SHA256SUMS 包含三个包的校验值。

生成依赖使用者自己的参考图片编辑工具及额度，本项目没有订阅、额度销售或托管推理。测试使用 Codex 内置 image_gen。原创 Skill 与代码使用 MIT；源照片及衍生示例保留来源许可。

像素版是生成式风格插画，不保证整数像素网格或固定调色板。长椅实际为 1087×1447，猫为 1086×1448；均为近似 3:4 竖版，详细尺寸见清单。纯图、人像、跨模型与分享率本轮未测试。

路线图已加入下一款：海贼王式“大航海悬赏令”，尚未生成或发布。
