# Photo Playground v0.4.0 · 八款独立照片 Skills

新增三款：微型纸雕、照片记忆册、日常说明书。每款附两个实测样例、原照片来源、实际提示词和审图记录。

本页集中提供全部八款独立 ZIP，可只下载想用的那一款。原有五款安装包逐字节保持原样；最新像素修订未替换既有版本。SHA256SUMS 覆盖全部八个 ZIP，每款另附单独校验文件。

解压后，把同名文件夹放进个人 Skills 目录，上传照片并指定 Skill。例如：

> 使用 $paper-scene-diorama，把这张照片做成微型纸雕，保留主体，不加文字。

> 使用 $photo-memory-book，把这张照片做成摊开的照片记忆册，中文标题、英文小字。

> 使用 $everyday-user-manual，把这张照片做成日常说明书，文案有一点冷幽默。

本轮在 Codex 内置 image_gen 中实测，未验证豆包或其他图片模型兼容性。记忆册是书册图片效果，不是可翻页软件。图片属于创意重构，不保证来源像素无损。安装包不包含第三方照片；样例保留原照片许可。

项目开源，生成能力与用量由使用者自己的环境提供，不托管推理或销售额度。
