# 像素视觉语言

采用亲切、明亮、有空气感的复古 2D 游戏插画。让人想保存的是自己熟悉的生活被重新绘制，而不是界面装饰。

- 用有意组织的方形色块和阶梯轮廓表现形体，暗、中、亮色形成簇；尽量统一视觉像素尺度。既不将原图简单马赛克，也不画平滑卡通后撒像素噪点。
- 画面以约 240×320 的低分辨率创作观感为起点，放大呈现清晰边缘；这是视觉目标，不保证模型输出实际整数网格。大图保留可见像素，避免每根毛都细描。
- 毛发等高频纹理容易把输出拉回像素化照片。先按轮廓与 3–5 个明暗色组简化，再保留眼睛、耳朵与代表性毛色块；审片时注意密集碎线是否压过了卡通形体。
- 配色从源照片提取，再适度提亮。猫眼睛、路灯、秋叶等来源强调色可以做焦点。每种材质以少量色阶表达，阴影用冷色，光面用暖色；避免全图棕黄滤镜。
- 保持平面或来源已有的透视。正面猫不强改等距小人，长椅保留斜向延伸和公园纵深。卡通化适度夸张表情，不抹掉身份特征。
- 场景占画面约 80–90%。若使用存档条，以 8–12% 的窄条安置短文字，小方形图标至多一个；不要大面积留白、大宋体海报或仿掌机塑料外壳。
- 中文选择清楚的方头字/像素感黑体，必要时文字可采用更细的网格以保证识读。不要为了装饰加入随机英文数字和乱码。
- 不加来源没有的魔法宠物、角色或道具。可以重组被遮挡的环境来适应竖版，但保持来源最重要的两项空间关系。

示例仅用于说明文案与可见场景的关系：桌边盯人的猫可写“今日任务：陪你摸鱼”；空长椅可写“在这里，暂停一下”。不将猫、树林或这两句文字固定为所有输出。
