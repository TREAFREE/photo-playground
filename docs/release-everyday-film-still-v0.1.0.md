# 日常电影剧照 v0.1.0

新增独立 Skill `everyday-film-still`：从日常照片出发，用构图、光源、景深和克制调色生成写实宽银幕剧照。默认纯图，可选原创短字幕。

首发实测三个题材：深夜桌边猫、黄昏空长椅、带“再坐一会儿吧。”字幕的清晨早餐。来源、实际提示词与审片记录均在仓库中。输出约 2.38:1，接近 2.39:1 目标，不承诺精确尺寸或原图无损。

下载本页 ZIP，解压后放入 Skills 目录。附图输入：

> 使用 $everyday-film-still，把这张照片做成电影剧照，保留主体特征，不加字幕。

这个版本只发布该 Skill。其他四款的规则与 ZIP 未改动；原有 v0.3.0 latest 入口保留。
